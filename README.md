# Mi chino HSK 1

App personal para estudiar chino (HSK 1, lecciones 1 a 3): lo básico, vocabulario con imágenes, tarjetas, test, hablar con nota, escritura a mano y conversaciones guiadas.

Ábrela en https://jmropolo-ropolo.github.io/my-chinapp/ con Safari (iPhone/iPad) o Chrome (Android). Para hablar, mantén pulsado el botón rojo del micrófono.
